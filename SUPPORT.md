# Support

Thanks for using HTML Tag Counter.

## How to get help

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/poluru-labs/chrome-edge-tag-analyzer/issues) |
| Feature request | [GitHub Issues](https://github.com/poluru-labs/chrome-edge-tag-analyzer/issues) |
| Security vulnerability | See [SECURITY.md](./SECURITY.md) — do **not** open a public issue |
| Docs / usage questions | GitHub Issues (label `question`) or email below |

## Before opening an issue

Please include:

- Extension version (`manifest.json`)
- Browser (Chrome or Edge) and version
- The page URL if you can share it (redact anything sensitive)
- Expected vs actual behavior
- Whether you loaded the unpacked folder that contains `manifest.json`
