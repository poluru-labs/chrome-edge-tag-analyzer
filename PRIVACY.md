# Privacy Policy

**Last updated:** 3 September 2026

HTML Tag Counter is a local Chrome / Edge extension maintained by **Subrahmanyam Poluru / Poluru Labs**.

## What this extension does

When you click **Analyze Page**, the extension reads the **current tab URL** and counts HTML tag names on that page (`div`, `p`, `a`, …). Counts are shown in the popup.

## What we collect

**Nothing.** The extension:

- Does not include analytics or crash reporters
- Does not make network requests
- Does not store tag counts
- Does not send data to Poluru Labs, GitHub, or any other server
- Does not persist data in `chrome.storage` or cookies

Results exist only in memory in the popup until you close it or click **Clear Results**.

## Permissions

| Permission | Why |
| --- | --- |
| `activeTab` | Access the tab you are looking at, only after you click Analyze Page |
| `scripting` | Run a one-shot tag count on that tab |

The extension does **not** inject a content script on every website.

## Restricted pages

Chrome and Edge block extensions on `chrome://` / `edge://` pages, the Web Store, and some other privileged URLs. That is expected.
